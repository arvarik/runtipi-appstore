# Contrack App Store for Runtipi

Custom [Runtipi](https://runtipi.io) app store for [Contrack](https://github.com/arvarik/contrack).

## Add to Runtipi

1. Open your Runtipi dashboard and go to **Settings → App Stores**.
2. Click **Add App Store**.
3. Paste `https://github.com/arvarik/runtipi-appstore` and save.
